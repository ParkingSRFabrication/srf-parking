# srf-parking
Railway Station Vehicle Parking Management App 🚉🅿️ A simple and user-friendly web application for managing vehicle parking at railway stations. The system helps users check parking availability, register vehicles, manage parking slots, and track parking details efficiently.
Key Features:

🚗 Vehicle registration & management
🅿️ Parking slot allocation
📊 Real-time parking availability
🎫 Entry & exit management
👤 User and admin management
💰 Parking fee tracking
📱 Responsive and easy-to-use interface
